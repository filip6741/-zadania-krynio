Zadanie 4 — teoria JavaScript

1) Kiedy powstał JavaScript (podaj datę).
JavaScript został stworzony w 1995 roku.

2) Dlaczego jest to język skryptowy?
Jest językiem interpretowanym; nie musi być skompilowany do kodu maszynowego, aby zobaczyć efekty działania.

3) Gdzie jest wykonywany JS (klient lub serwer)?
W przeglądarce internetowej po stronie klienta; może być też uruchamiany po stronie serwera, np. z Node.js.

4) Dlaczego JS jest bezpiecznym narzędziem?
JavaScript ma znacznie ograniczone uprawnienia dostępu do zasobów komputera.

5) Czy jest to język obiektowy, jeśli tak to dlaczego?
Tak. Wykorzystuje definicje obiektów, metod i zdarzeń do opisu właściwości obiektów.

6) Wymień zalety JS:
Zaleta 1: prostota. Zaleta 2: wiele praktycznych przykładów w Internecie. Zaleta 3: uniwersalność oraz możliwość odciążenia serwerów i ograniczenia przesyłanych danych.

7) Framework to:
Rodzaj programu do tworzenia innych programów w JavaScript.

8) Do aplikacji mobilnych można użyć Framework:
React Native.

9) Aplikacje responsywne to:
Aplikacje, w których rozmiar, układ lub widoczność treści dostosowują się do rozmiaru ekranu.

10) Kod input button — wyjaśnienie
<input type="button" name="przycisk" value="Nowa Strona" onclick="WinOpen()"> tworzy przycisk „Nowa Strona”; po kliknięciu wywołuje funkcję WinOpen.

11) Kod window.open — wyjaśnienie
window.open("obraz.html","okienko","toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200"); otwiera obraz.html w nowym oknie o podanej nazwie i parametrach.

12) Opisz window.close()
Zamyka bieżące okno przeglądarki, jeśli przeglądarka pozwala skryptowi je zamknąć.

Opcje okna:
toolbar=no — ukrywa pasek narzędzi;
directories=no — ukrywa przyciski katalogów;
menubar=no — ukrywa pasek menu;
height=280 — wysokość okna;
width=160 — szerokość okna;
top=200 — odległość od górnej krawędzi ekranu;
left=200 — odległość od lewej krawędzi ekranu.

Znaki < i > można wyświetlić jako &lsaquo; i &rsaquo; albo umieścić kod w elemencie textarea.
