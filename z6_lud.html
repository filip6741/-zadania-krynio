Filip Ludka — Zadanie 6

1) Rodzaje okienek
alert wyświetla informację i przycisk OK. prompt pozwala wpisać wartość zwracaną do programu. confirm służy do potwierdzania decyzji.

2) Konwersja liczb
parseFloat(zmienna) konwertuje do typu zmiennoprzecinkowego, parseInt(zmienna) do typu całkowitego, a toString(zmienna) do łańcucha znaków. Wartość pobrana przez prompt jest ciągiem znaków, dlatego przed obliczeniami należy ją skonwertować.

3) Trzy zasady nazw zmiennych
1. Nazwa zaczyna się od litery, $ lub _ i zawiera litery bez polskich znaków, cyfry, $ lub _.
2. Wielkość liter ma znaczenie.
3. Nie należy używać słów kluczowych JavaScript jako nazw zmiennych.

4) Typy zmiennych w JavaScript
Number — liczbowy, całkowity lub zmiennoprzecinkowy;
String — tekstowy;
Boolean — logiczny;
Null — pusta zawartość;
Undefined — typ niezidentyfikowany;
Object — obiekt.
